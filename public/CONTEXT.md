# Public Assets Context

## Purpose
`public/` contains static assets served by the public website.

## Belongs here
Approved, optimized public assets such as the authoritative Foundation logo.

## Does not belong here
Secrets, student data, unreviewed generated media, source documents, or private files.

## Inputs and outputs
Inputs are approved brand assets. Outputs are browser-accessible static files.

## Before modifying
Read `REFERENCE.md`, the Brand Constitution, and `app/CONTEXT.md`.
