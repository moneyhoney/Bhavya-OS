# References Context

## Purpose
`references/` is the stable Layer 3 source-material boundary.

## Belongs here
Approved governance/brand material, the ICM paper, and clearly labelled visual references.

## Does not belong here
Run outputs, drafts, credentials, generated application data, or fabricated institutional content.

## Inputs and outputs
Inputs are supplied source materials. Outputs are inspectable guidance consumed by bounded implementation stages.

## Before modifying
Read root `REFERENCE.md` and preserve source hierarchy and provenance.
