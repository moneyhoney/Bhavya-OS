# Bhavya Design System Context

This skill owns the reusable frontend quality rules for the public website and learning platform: visual tokens, typography, responsive behavior, accessibility, interaction states, purposeful motion, performance, dependency evaluation, provenance, and browser QA.

Load `SKILL.md` for procedures. The current implementation uses Next.js App Router, React, TypeScript, custom CSS, static export, and a focused `lucide-react` icon dependency. It does not use Tailwind, shadcn/ui, Radix globally, GSAP, React Bits, Tremor, React Three Fiber, visx, AI Elements, or the Vercel AI SDK.

The skill must preserve the authoritative Foundation logo and source hierarchy, support low-bandwidth mobile learners, and keep the Bhavya editorial system distinct from generic SaaS/dashboard patterns.
