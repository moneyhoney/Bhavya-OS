# Bhavya Learning

## Purpose
Turn durable AI concepts into clear, practical, review-ready learning experiences without presenting proposals as approved curriculum.

## Trigger
Use for learning routes, module or lesson design, experiment concepts, curriculum mapping, or education UX.

## Inputs
Approved Foundation sources, current curriculum context, learner constraints, objective, and license-aware resource map.

## Workflow
1. State the learner objective and prior knowledge.
2. Structure the experience as Understand → Observe → Try → Experiment → Build → Reflect.
3. Prefer durable concepts: data, instructions, models, evaluation, verification, bias, and responsible use.
4. Make proposed status explicit and avoid fabricated facts, student data, or course claims.
5. Add a low-bandwidth, no-account path and an appropriate human review gate.

## Outputs
Original learning structure, module metadata, interaction copy, and links to sources without copying their content.

## Validation
Check age-appropriate clarity, accessibility, factual boundaries, source provenance, and that every activity can be completed without hidden services.

## Failure conditions
Stop when content depends on unreviewed policy, unsafe child communication, invented Foundation activity, or unclear reuse rights.
