# Skills Context

## Purpose
`skills/` contains small, Bhavya-specific operating playbooks that agents load only when a task matches their trigger.

## Routing
- `bhavya-ui`: visual and interaction work.
- `bhavya-learning`: proposed learning architecture and lesson design.
- `bhavya-source-integrity`: source, license, provenance, and Foundation-claim review.

## Boundary
Skills describe inspectable work and validation. They do not replace `AGENTS.md`, authoritative Foundation documents, or human review.
