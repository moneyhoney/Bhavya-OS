## Interpretable Context Methodology

The supplied ICM paper describes a filesystem-based approach to sequential, human-reviewed AI workflows.

Relevant principles:
- one stage, one job;
- plain text as an interface;
- layered context loading;
- every output as an edit surface;
- stable reference material separated from per-run working artifacts;
- numbered folders for stage order;
- stage CONTEXT.md files defining inputs, process, outputs, validation, and review;
- human review at stage boundaries.

Use ICM as an architectural methodology for agent-assisted content/product workflows. It does not override Foundation governance.
