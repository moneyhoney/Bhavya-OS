# Governance / Foundation Knowledge Context

## Purpose

`governance/` is the routing room for institutional facts, governance, safeguarding, responsible AI, digital-library, environmental, and brand questions. It is a context boundary, not a duplicate governance corpus.

## Read next

- `REFERENCE.md` for the source hierarchy and durable interpretation rules.
- `references/source-material/foundation-constitution/` for the supplied Foundation source files.
- `references/source-material/Interpretable-Context-Methodology.txt` for ICM workflow guidance.
- `public/logo.png` only when the authoritative logo asset is required.

## Current state

- **Implemented:** source routing, logo provenance, and truth boundaries.
- **Proposed:** product implementations that may later express governance requirements.
- **Not started:** legal, policy, safeguarding, or operational systems not explicitly supported by approved source material.

## Workflow

Classify the question as Foundation-authoritative, approved product, reviewed educational content, external reference, or unknown. Read the smallest relevant source. Record assumptions when necessary. Require human review before treating drafts as official policy, curriculum, publication, or safeguarding procedure.

## Non-negotiables

Never invent institutional facts, locations, statistics, programmes, partnerships, impact, legal requirements, student data, lab details, or policy language. Reference images are visual inspiration only; their dummy data is never Foundation truth.
