# Curriculum Stage Context

This folder is a Layer 3/4 boundary for proposed learning architecture and provenance-aware resource research.

Inputs: PRD, governance references, Brand Constitution, ICM methodology, and first-party educational resource documentation.

Process: define durable concepts before tools, map each module to Learn → Try → Build → Reflect, record source/license implications, and identify Foundation review gates.

Outputs: proposed curriculum maps and resource metadata. Outputs are not approved curriculum.

Validation: every proposal is labelled, every external resource has license notes, and no third-party content is copied.

Human review: Foundation review is required before publication as official learning content.

Failure conditions: fabricated curriculum claims, unsupported age claims, copied protected content, or unsafe community functionality.
